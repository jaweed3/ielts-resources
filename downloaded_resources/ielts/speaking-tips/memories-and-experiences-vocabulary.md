In the left column are the words that are quite common or the candidate uses incorrect semantics. In the right column are the words you should use when taking the IELTS test to get a high score.

|     |     |     |
| --- | --- | --- |
| **Quite common** | **Should use** | **Example** |
| Unforgettable | Memorable/impressive | The gig I went to last weekend was so memorable. |
| Memory | A lasting impression | This film left a lasting impression on my mind. |
| A rare opportunity | A once-in-a-lifetime chance | This is a once-in-a-lifetime chance, I won't let it go. |
| In my memory | In retrospect | In retrospect, I made the right decision at the very beginning. |
| Remember | Recall | We recalled all good memories we had in high school. |
| Starting point | Incentive | The incentive was that I wanted to extend my own limits. |
| Get married | Tie the knot (infml) | Today is the big day for my sister to tie the knot. |
| Wedding dress | Wedding gown | This exquisite wedding gown is handmade. |
